# BlockBook для Android

BlockBook — приложение для заметок, списков, рисунков и работы с идеями на свободном холсте.

**Актуальная версия: 0.3.6 · 11 ноября 2026 года. Android 8.0 и новее.**

[Скачать APK 0.3.6](https://github.com/AlemusSs/BlockBook/releases/download/v0.3.6/BlockBook_0.3.6_code12.apk) · [Последний выпуск](https://github.com/AlemusSs/BlockBook/releases/latest) · [История выпусков](CHANGELOG.md)

## Возможности

- Блочные проекты: свободный холст, масштабирование и перемещение, текстовые блоки, изображения, чек-листы, рамки, связи между блоками, стрелки и подписи.
- Текстовые записи: отдельное название и заголовок, основной текст, жирное, наклонное и подчёркнутое начертание, отмена и возврат действий.
- Рисунки: рисование пальцем, ручка и маркер, выбор толщины, палитра из 28 цветов, дополнительная толщина по скорости, ластик для фрагментов, масштабирование и показ всего рисунка.
- Чек-листы: заголовок, добавление пунктов, отметки выполнения, изменение порядка удержанием трёх точек, выполненные пункты в отдельной части списка.
- Главный экран: карточки с превью или строчный список, изменение порядка записей, массовое удаление, корзина, автоматическое сохранение.
- Темы оформления, виброотклик, настройки линий и сетки, справка внутри приложения.
- Защита входа PIN-кодом и биометрией, блокировка отдельных проектов паролем, мозаика содержимого защищённых карточек.
- Зашифрованная резервная копия с паролем и восстановление из файла, экспорт изображения холста, напоминания у блоков.
- Проверка обновлений при запуске и вручную из настроек. Перед загрузкой показываются изменения, при загрузке — проценты, затем открывается системная установка.
- Вкладка «Календарь» пока содержит временную заглушку; функции календаря появятся позже.

## Установка и обновление

1. Скачайте APK по ссылке выше и откройте файл на телефоне.
2. При первом запуске установки Android может попросить разрешить установку для браузера или файлового менеджера, из которого вы открываете APK.
3. Подтвердите установку. Для обновления уже установленной основной версии устанавливайте APK поверх неё: записи сохраняются. Не удаляйте приложение перед обновлением.
4. Начиная с 0.3.6 приложение проверяет GitHub при запуске. Можно нажать «Позже» и продолжить работу. Вручную: **Настройки → Обновления → Проверить обновления**.
5. При первой установке из приложения разрешите BlockBook устанавливать обновления в системных настройках. После загрузки и проверки файла Android откроет подтверждение установки. Скрытой установки без участия пользователя нет.

Перед важным обновлением рекомендуется сделать резервную копию в разделе аккаунта и сохранить пароль. Проекты хранятся на устройстве; удаление приложения может удалить локальные записи.

**Ранние тестовые установки.** Если Android сообщает о конфликте пакета/подписи или приложение использует пакет `.fixcheck`, это отдельная старая тестовая цепочка. Сначала экспортируйте резервную копию из неё, установите основную версию и восстановите копию. Убедитесь, что записи восстановлены, прежде чем удалять тестовую установку. APK из этого репозитория обновляет основной пакет `com.example.blockbook`; старые установки без функции обновления необходимо один раз обновить вручную.

## Конфиденциальность и обновления

Создавать аккаунт GitHub для скачивания не нужно. Для проверки обновлений приложение обращается к публичному API GitHub, для загрузки APK — к GitHub Releases. Содержимое ваших записей, резервных копий и пароли в эти запросы не включаются. GitHub получает обычные технические сведения сетевого запроса, включая IP-адрес. Для работы с локальными записями интернет не требуется.

Перед установкой проверяются SHA-256, размер файла, имя пакета, номер версии и соответствие подписи установленному приложению. При ошибке загрузки можно продолжать работу со старой версией и повторить попытку позже.
